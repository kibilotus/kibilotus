# 2단계: 백그라운드 스케줄러

## 동작 방식 (메인 폰 기준)

```
[슬롯 알람] 00/02/04…22시 + 1~5분 지터 ─┐
[잠금 해제] USER_PRESENT ──────────────────┼─▶ TriggerPolicy
[접근성 서비스 연결] (재부팅 후 등) ───────┘        │
                                                     ├─ 미완료 미션 없음 / 이번 슬롯 이미 시도 → 무시
                                                     ├─ 잠김·화면 꺼짐 → 다음 잠금 해제까지 대기
                                                     └─ 실행 가능 → "10초 후 토스 자동 실행 [취소]" 알림
                                                                        ├─ 취소 → 이번 슬롯 건너뜀
                                                                        └─ 10초 경과 → 배치 실행 ("실행 중 [중지]" 알림)
```

- **슬롯당 1회**: 2시간 슬롯마다 최대 한 번만 시도합니다. 같은 슬롯 안에서 잠금을 여러 번 풀어도 다시 뜨지 않습니다.
- **미완료만 실행**: 미션마다 완료 상태가 초기화되는 주기가 다릅니다.

  | 미션 | 주기 |
  |---|---|
  | 출석체크 | 하루 (자정 초기화) |
  | 버튼 누르기 | 3시간 회차 (하루 8번) |

  2시간 슬롯(0, 2, 4, … 22시)이 3시간 회차 8개를 모두 덮기 때문에, 폰을 자주 켜면 8회를 모두 받을 수 있습니다.
- **재시도**: `FAILED`, `BLOCKED`는 다음 슬롯에 다시 시도합니다. `BLOCKED`가 나오면 그 배치의 나머지 미션은 실행하지 않습니다.
- **지터**: 슬롯 알람에만 1~5분 랜덤 지연을 더합니다. 잠금 해제 경로는 실행 시각이 원래 불규칙하므로 따로 더하지 않습니다.
- **미션 사이 간격**: 3~10초 랜덤

## 구성 요소

| 파일 | 역할 |
|---|---|
| `core/schedule/SlotSchedule.kt` | 슬롯 계산 (KST), `Jitter` |
| `core/schedule/TriggerPolicy.kt` | 지금 실행할지 판단 (순수 함수, 단위 테스트) |
| `core/schedule/BatchRunner.kt` | 미완료 미션 필터, 순차 실행, 상태 저장 |
| `core/Mission.kt` `Period` | 미션별 초기화 주기 (`Daily`, `EveryHours(3)`) |
| `app/Autopilot.kt` | 트리거 → 카운트다운 → 배치 실행 컨트롤러 |
| `app/AlarmScheduler.kt` | `setExactAndAllowWhileIdle` 알람 (권한 없으면 비정확 알람) |
| `app/AutomationService.kt` | 잠금 해제 수신자 등록. 상주 프로세스 역할도 합니다 |
| `app/Receivers.kt` | 알람, 취소/중지 액션, 재부팅·시간 변경 시 알람 재등록 |
| `app/AutopilotPrefs.kt` | 미션 상태, 마지막 시도 슬롯 (3단계에서 실행 이력은 DB로 이전) |

## 안전장치
- 알림 권한이 없으면 자동 실행하지 않습니다. 취소할 기회 없이 화면을 빼앗지 않기 위해서입니다.
- 카운트다운 중에 화면을 끄면 실행하지 않고, 다음 잠금 해제까지 기다립니다.
- 실행 중 "중지"를 누르면 현재 미션이 `CANCELLED`로 끝나고, 다음 슬롯에 다시 시도합니다.
- 접근성 서비스가 꺼져 있으면 경고 알림을 슬롯당 1번 보냅니다.

## 설정 (앱 화면 두 번째 버튼을 반복해서 누르면 순서대로 요청)
1. 알림 권한 (Android 13 이상)
2. 정확한 알람 (Android 12 이상, 거부하면 알람이 수 분 늦어질 수 있음)
3. 배터리 최적화 예외. 삼성은 추가로 "설정 → 배터리 → 백그라운드 사용 한도"에서 **절전 예외 앱**에 넣어 주세요.
