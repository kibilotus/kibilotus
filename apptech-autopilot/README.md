# 앱테크 오토파일럿

토스 등 앱테크 서비스의 출석체크/포인트 미션을 Android 폰 안에서 자동으로 수행하는 앱입니다.
AccessibilityService로 화면을 제어하고, 앱 내부 스케줄러로 2시간마다 미완료 미션만 다시 시도합니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 토스 자동화 메커니즘 검증 & 코어 로직 | 실기기 보정 중 → [docs/STAGE1.md](docs/STAGE1.md) |
| 2 | 00:00부터 2시간 주기 백그라운드 스케줄러 (+1~5분 지터, 잠금 해제 시 보충 실행) | 구현 → [docs/STAGE2.md](docs/STAGE2.md) |
| 3 | 결과 DB 저장, 연속 실패 알림 (텔레그램) | 예정 |
| 4 | 예외 처리 강화, 멀티 앱 확장 인터페이스 | 예정 |
